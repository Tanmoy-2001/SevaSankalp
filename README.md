# SevaSankalp

An online healthcare appointment platform designed to make access to healthcare services more convenient through digital scheduling and patient-support features.

## Project overview

SevaSankalp brings several healthcare-related workflows together in one platform. The project description includes appointment scheduling, digital payments, health alerts, emergency links, a health blog, and an interactive chatbot.

## Key features

- Online doctor appointment booking and scheduling
- Digital payment workflow
- Health alerts and emergency access links
- Health information blog
- Interactive chatbot for patient support
- Machine-learning component intended to support scheduling optimization

## Project goals

- Simplify the appointment booking journey
- Bring patient-support information into one place
- Explore how automation and machine learning can support healthcare workflows
